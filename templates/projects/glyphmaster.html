Glyphmaster

Sep - Dec 2024

Technologies: WebGL, Three.js, Socket.io, JavaScript

Overview

Glyphmaster is a 3D RPG game where players draw glyphs to cast spells and battle monsters in a fantasy world. It features both single-player and real-time multiplayer modes.

Key Features

  • Implemented a magic glyph identification algorithm that recognizes player-drawn shapes using mouse or hand input.
  • Created a real-time multiplayer mode with Socket.io, synchronizing player movements, spells, and game states.
  • Built immersive 3D environments with Three.js, including lighting, shadows, and animations.
  • Designed multiple enemy types with AI behavior and spell effects.

Technical Highlights

  • Custom gesture recognition system for glyph drawing.
  • Network synchronization with low latency using WebSockets.
  • Modular code architecture for easy addition of new spells and enemies.
